# Intent categories

Four categories for how a user expresses a search need.

## goal

A desired outcome stated as an objective ("create a new branch", "sync with remote"). Forward-looking and intentional.

## error_message

Language that mirrors or paraphrases a Git error, warning, or fatal message the user saw in the terminal.

## symptom

Observable broken state without naming the command ("I have two copies of the same commits", "nothing shows up in git status but files changed").

## conversational

Natural, chatty, or incomplete phrasing as typed in a hurry ("help unstick rebase", "wait how do I undo commit but keep changes").
